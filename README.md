## Online Store Retail SQL Project

## About
This project is a simple Online Store Retail Database built using MySQL. It includes database creation, sample data, and SQL queries to analyze customers, products, orders, and payments.
- ## Features
- Created a relational database with five tables
- Implemented Primary Key and Foreign Key relationships
- Inserted sample data
- Performed SQL queries using JOINs and Aggregate Functions
- Generated business insights from the data

## Technologies Used
- SQL
- MySQL Workbench
- GitHub

## Database Schema
Tables:
- Customers
- Products
- Orders
- Order_Items
- Payments

## SQL Concepts Used
- CREATE DATABASE
- CREATE TABLE
- INSERT
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- Aggregate Functions (COUNT, SUM, AVG, MIN, MAX)
- INNER JOIN
- Primary Key
- Foreign Key

## Project Structure
```
online-store-retail-sql-project/
├── schema.sql
├── data.sql
├── queries.sql
└── README.md
```

## How to Run
1. Open MySQL Workbench.
2. Execute `schema.sql` to create the database and tables.
3. Execute `data.sql` to insert sample data.
4. Execute `queries.sql` to run SQL queries.
